## Tema 1: Método Analítico
Este repositorio contiene la implementación de distintos algoritmos para la generación de números pseudoaleatorios. 
El objetivo del proyecto es estudiar, analizar y comparar diversos métodos para generar secuencias numéricas que aparenten aleatoriedad utilizando procedimientos determinísticos.

## 📌 Objetivos
Implementar generadores de números pseudoaleatorios.
Evaluar la calidad de los números generados mediante tests.
Comparar el rendimiento y distribución de diferentes algoritmos.
Aplicar los generadores en simulaciones o aplicaciones prácticas.
